# 星界工坊 · 星图关卡

13 个关卡从一开始即可选择。关卡编号表示建议游玩顺序；玩家可以直接挑战任何星图，已有存档中的最高分、星级仍然保留。

关卡不是填满的高血量砖墙：外环开口、放射通道、迷宫门洞和错层结构使球能进入内部连续反弹。大多数砖块只需一次命中，颜色、轮廓和击碎节奏共同表现不同的宇宙建筑。

| --- | --- | --- |

| 02 | 光子花园 | 六瓣光环围绕金色花芯；每个花瓣都有独立切入角度 |

## 编辑与生成

文件名使用 `level-NN.json`。现代版本由 `web/game/build-legacy.cjs` 按文件名顺序读取；`npm run dev`、`npm run build` 和 `npm test` 会自动更新关卡模块。旧版 `build.js` 也读取同一目录。

关卡的完整几何源文件位于 `tools/generate-levels.cjs`，无需第三方依赖：

```sh
node tools/generate-levels.cjs
```

生成器使用确定性的几何构造，重新生成不会改变随机种子或布局。执行时会验证坐标、重复砖块、颜色、血量分布与砖区高度，并输出每关的砖数、总血量、球速、挡板宽度和生命数。直接修改 JSON 也能生效；如果需要保留修改，请同时修改生成器，因为下次生成会覆盖这些 JSON 文件。

## 数据格式

```json
{
  "name": "关卡1 - 星环启航",
  "gridWidth": 28,
  "gridHeight": 24,
  "ballSpeed": 295,
  "paddleWidth": 112,
  "lives": 5,
  "bricks": [
    { "row": 1, "col": 2, "hp": 1, "color": "#45b9df" },
    { "row": 1, "col": 3, "hp": 2, "color": "#61e0ed" },
    { "row": 2, "col": 4, "hp": 3, "color": "#fff1ba" }
  ]
}
```

| 字段 | 含义 |
| --- | --- |
| `name` | 显示名称 |
| `gridWidth` / `gridHeight` | 网格列数和行数；不是像素尺寸 |
| `ballSpeed` | 初始球速，逻辑像素/秒 |
| `paddleWidth` | 挡板初始宽度，逻辑像素 |
| `lives` | 初始生命数 |
| `bricks` | 非空砖块列表；每个位置只能出现一次 |
| `bricks[].row` / `col` | 从 0 开始的整数网格坐标，必须在网格内 |
| `bricks[].hp` | 需要命中的次数；本套关卡使用 `1`、`2`、`3`、`10` |
| `bricks[].color` | 可选的十六进制颜色；显式颜色优先，否则由 HP 主题配色 |

## 几何与可玩性约束

游戏使用 `375 × 667` 的逻辑画布。左右各留 10 像素，砖缝为 2 像素，砖块是正方形。对于列数 `W`：

```text
砖格步长 = 357 / W
砖块边长 = 357 / W - 2
砖块顶边 = 90 + row × 357 / W
砖块底边 = 90 + (row + 1) × 357 / W - 2
```

本套关卡使用 28–36 列，砖区底边不超过 400 像素，与初始挡板中心 `y = 567` 之间保留至少 167 像素。基础球直径为 8 像素，留空一列形成的净通道至少约 11.9 像素；大型入口通常留空两到四列。普通 2 像素砖缝不能当作可通行道路。

生成器将每关控制在 180–550 块砖、平均血量不超过 1.65、装甲砖不超过 3%。当前球速为 295–365，挡板为 94–112，生命数为 4–5。复杂度主要来自布局、入口和反弹路线。

所有砖块都可摧毁，都计入通关条件。`hp: 10` 是需要十次普通命中的装甲砖，只有最后两关各使用四块；旧数据中的 `999` 在引擎中也会转换成 10 HP 装甲砖。火球会直接摧毁普通砖，对装甲砖每次只造成一点伤害。

颜色在每个关卡内形成强度层级：普通砖使用饱和底色，双血砖更明亮，三血核心接近白色，装甲节点为银蓝色。星图原始颜色由 JSON 保存；运行时应深拷贝后再调整，不应覆盖原数据。
